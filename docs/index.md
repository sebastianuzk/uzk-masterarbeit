# WiSo Chatbot Documentation

Ein autonomer Chatbot-Agent für die WiSo-Fakultät der Universität zu Köln.

## 🎯 Überblick

Intelligenter Chatbot mit:

- ✅ **RAG-System** mit 329 kategorisierten Dokumenten
- ✅ **Open-Source LLM** (Ollama)
- ✅ **Multi-Tool Agent** (LangGraph)
- ✅ **KLIPS2-Integration**
- ✅ **Vollständig lokal**
